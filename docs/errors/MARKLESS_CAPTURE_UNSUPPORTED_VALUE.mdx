**Error** from the compiler, while it builds your `.tsrx` files.

## What happened

Markless prints the message, the reason, and a suggestion:

```text
MARKLESS_CAPTURE_UNSUPPORTED_VALUE: Cannot capture "<name>" in lazy <kind> symbol "<symbolId>" because local <bindingKindLabel> values cannot cross a resume boundary.
Lazy symbols run after browser resume. Captures must be graph references, element handles, props/shared values, module imports, or serializable constants.
https://markless.dev/errors/MARKLESS_CAPTURE_UNSUPPORTED_VALUE
```

Words in angle brackets change from case to case.
