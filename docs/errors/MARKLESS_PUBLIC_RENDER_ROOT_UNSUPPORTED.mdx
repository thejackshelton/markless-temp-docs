**Error or warning** from the compiler, while it builds your `.tsrx` files.

## What happened

Markless prints the message, the reason, and a suggestion:

```text
MARKLESS_PUBLIC_RENDER_ROOT_UNSUPPORTED: No component with a TSRX template root was found, so the compiled module would render nothing.
Markless anchors each component's HTML and interactivity to a single root element. Without a supported root the component would silently render nothing, so the compiler stops with an error instead.
Export a TSRX component with an @{...} template body, or pass an explicit compiled component artifact when multiple roots exist.
https://markless.dev/errors/MARKLESS_PUBLIC_RENDER_ROOT_UNSUPPORTED
```

## How to fix it

Start with the suggestion in the message above.

If you accept the warning on purpose, put this comment on the line above it:

```tsrx
// markless-allow MARKLESS_PUBLIC_RENDER_ROOT_UNSUPPORTED: the reason you accept it
```
