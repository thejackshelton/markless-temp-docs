**Error** from the compiler, while it builds your `.tsrx` files.

## What happened

Markless prints the message, the reason, and a suggestion:

```text
MARKLESS_STATE_DYNAMIC_PATH_WRITE: Cannot write to "<target>" because graph write paths must be statically resolvable.
The resumable state graph records path-level writes in the payload and runtime journal. A dynamic property expression cannot be represented as a stable graph path by the current compiler pass.
Use a statically named property path, a literal array index, or a collection method with compiler coverage for this state update.
https://markless.dev/errors/MARKLESS_STATE_DYNAMIC_PATH_WRITE
```

Words in angle brackets change from case to case.

## How to fix it

Start with the suggestion in the message above.
