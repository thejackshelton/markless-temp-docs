**Warning** from the compiler, while it builds your `.tsrx` files.

## What happened

Markless prints the message, the reason, and a suggestion:

```text
MARKLESS_ASYNC_ARM_RENDER_UNSUPPORTED: The settled @try content cannot render in the browser yet
The compiler emits a browser-side render module for @try/@catch content so it can update after the data settles. A shape the module cannot render would silently stay frozen, so the compiler reports it instead.
https://markless.dev/errors/MARKLESS_ASYNC_ARM_RENDER_UNSUPPORTED
```

## How to fix it

If you accept the warning on purpose, put this comment on the line above it:

```tsrx
// markless-allow MARKLESS_ASYNC_ARM_RENDER_UNSUPPORTED: the reason you accept it
```
