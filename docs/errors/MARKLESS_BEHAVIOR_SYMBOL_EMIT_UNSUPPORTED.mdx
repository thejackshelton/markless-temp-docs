**Error** from the compiler, while it builds your `.tsrx` files.

## What happened

Markless prints the message, the reason, and a suggestion:

```text
MARKLESS_BEHAVIOR_SYMBOL_EMIT_UNSUPPORTED: Cannot emit lazy behavior symbol "<symbolId>" because it reads component-local "<name>", a local <bindingKindLabel> value that cannot cross a resume boundary.
Element behavior symbols run after browser resume. Behavior factories may use module functions, graph inputs, element handles, props/shared values, or serializable capture-plane inputs; unsupported body locals would otherwise become missing behavior code.
https://markless.dev/errors/MARKLESS_BEHAVIOR_SYMBOL_EMIT_UNSUPPORTED
```

Words in angle brackets change from case to case.
