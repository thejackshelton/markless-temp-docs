**Error** from the compiler, while it builds your `.tsrx` files.

## What happened

Markless prints the message, the reason, and a suggestion:

```text
MARKLESS_SYNC_POLICY_UNEXTRACTABLE: `<source>` detaches <action> from the event, so the compiler cannot prove when the default action is cancelled for <attributeName>.
preventDefault() and stopPropagation() must run before lazy handler symbols load; a detached reference hides which action runs and under what condition.
Call it directly on the event parameter instead of detaching <action>.
https://markless.dev/errors/MARKLESS_SYNC_POLICY_UNEXTRACTABLE
```

Words in angle brackets change from case to case.

Start with the suggestion in the message above.
