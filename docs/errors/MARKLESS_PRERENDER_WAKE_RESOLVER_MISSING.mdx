**Error** from the compiler, while it builds your `.tsrx` files.

## What happened

Markless prints the message, the reason, and a suggestion:

```text
MARKLESS_PRERENDER_WAKE_RESOLVER_MISSING: MARKLESS_PRERENDER_WAKE_RESOLVER_MISSING
A wake variant that carries symbols must hand its symbol routes to a generated resolver; without one the routes would have no owner.
Emit the generated symbol resolver alongside the wake variant.
https://markless.dev/errors/MARKLESS_PRERENDER_WAKE_RESOLVER_MISSING
```

## How to fix it

Start with the suggestion in the message above.
