**Error** from the compiler, while it builds your `.tsrx` files.

## What happened

Markless prints the message, the reason, and a suggestion:

```text
MARKLESS_SOURCE_SYMBOL_CLAIMS_DIVERGED: MARKLESS_SOURCE_SYMBOL_CLAIMS_DIVERGED: Source <source> has incompatible emitted symbol claims in <firstOwner> and <secondOwner>.
Merging contradictory claims would let one emitted sibling silently redefine a symbol another sibling already routes to.
Rebuild the source so every emitted sibling publishes the same rows for a shared symbol, and clear any stale build cache.
https://markless.dev/errors/MARKLESS_SOURCE_SYMBOL_CLAIMS_DIVERGED
```

Words in angle brackets change from case to case.

## How to fix it

Start with the suggestion in the message above.
