**Error** from the compiler, while it builds your `.tsrx` files.

## What happened

Markless prints the message, the reason, and a suggestion:

```text
MARKLESS_TEMPLATE_READ_UNDECLARED: Template read is not declared in render scope
Public CSR and SSR render modules execute template expressions directly during initial render. An identifier that is not declared in the emitted render scope would crash instead of rendering HTML.
Declare <name> in the component body, pass it as a prop, import it, or hoist it to a module-scope declaration before reading it in the template.
https://markless.dev/errors/MARKLESS_TEMPLATE_READ_UNDECLARED
```

Words in angle brackets change from case to case.

## How to fix it

Start with the suggestion in the message above.
