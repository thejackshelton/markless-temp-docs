**Error** from the compiler, while it builds your `.tsrx` files.

## What happened

Markless prints the message, the reason, and a suggestion:

```text
MARKLESS_OVERLAY_VALUE_UNSUPPORTED: <bound>. overlay must be written on the element itself as bare `overlay`, `overlay={true}`, or `overlay={false}`.
Elevation is structural, not reactive. The overlay record carries no inputs, so it has no dependencies and can never re-run; a value that varies at runtime would have nothing to re-elevate the element.
Let `@if` decide whether the element exists and keep `overlay` a literal on the element inside the branch.
https://markless.dev/errors/MARKLESS_OVERLAY_VALUE_UNSUPPORTED
```

Words in angle brackets change from case to case.
