**Error** from the runtime, while a page renders or runs.

## What happened

The error message reads:

```text
MARKLESS_ROW_COMPONENT_INTERACTIVE: <<componentName>> inside a @for row keyed by position has its own state, events, or async content, so its interactions cannot resume: an index key carries no row value to route them to. Key the @for by a stable field of the item, or keep components in index-keyed rows presentational (markup from item props, like <Link>).
https://markless.dev/errors/MARKLESS_ROW_COMPONENT_INTERACTIVE
```

Words in angle brackets change from case to case.
