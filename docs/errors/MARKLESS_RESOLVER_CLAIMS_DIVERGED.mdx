**Error** from the compiler, while it builds your `.tsrx` files.

## What happened

Markless prints the message, the reason, and a suggestion:

```text
MARKLESS_RESOLVER_CLAIMS_DIVERGED: MARKLESS_RESOLVER_CLAIMS_DIVERGED: Resolver <resolverId> has incompatible final claim sets.
Neither claim set contains the other, so accepting either would drop symbol routes the resolver still owns.
Rebuild the owning module so both publications claim the same set.
https://markless.dev/errors/MARKLESS_RESOLVER_CLAIMS_DIVERGED
```

Words in angle brackets change from case to case.

## How to fix it

Start with the suggestion in the message above.
