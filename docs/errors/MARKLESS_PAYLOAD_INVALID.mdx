**Error** from the runtime, while a page renders or runs.

## What happened

Markless prints the message, the reason, and a suggestion:

```text
MARKLESS_PAYLOAD_INVALID: Missing <type> payload script.
The markless/state payload did not match the resumability protocol shape required by this runtime.
Regenerate the markless/state payload with the matching markless compiler/runtime version.
https://markless.dev/errors/MARKLESS_PAYLOAD_INVALID
```

Words in angle brackets change from case to case.

## How to fix it

Start with the suggestion in the message above.
