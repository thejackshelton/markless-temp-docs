**Error** from the compiler, while it builds your `.tsrx` files.

## What happened

Markless prints the message, the reason, and a suggestion:

```text
MARKLESS_ELEMENT_HANDLE_IDREF_UNBOUND: Cannot resolve <attributeName>={<source>} because "<handleName>" is never bound with el={<handleName>} in this component.
An IDREF position names another element. With no el={handle} binding there is no element to name, so the compiler would emit an attribute pointing at nothing - a silently broken relationship that renders correctly and helps nobody.
Bind the handle to the element it names with el={<handleName>}, or remove the <attributeName> attribute.
https://markless.dev/errors/MARKLESS_ELEMENT_HANDLE_IDREF_UNBOUND
```

Words in angle brackets change from case to case.
