**Warning** from the build tools, while Vite builds or serves your app.

## What happened

The error message reads:

```text
MARKLESS_DEPRECATED_OPTION: `experimentalNativePacking` is deprecated. Native packing is on by default for client production builds; remove the option, or set `packing: false` to opt out.
```

## How to fix it

If you see this error, open an issue on the [Markless repo](https://github.com/compiled-run/markless/issues) with the steps that cause it.
