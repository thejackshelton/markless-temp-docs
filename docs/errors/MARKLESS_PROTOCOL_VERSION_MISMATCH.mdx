**Error** from the runtime, while a page renders or runs.

## What happened

Markless prints the message, the reason, and a suggestion:

```text
MARKLESS_PROTOCOL_VERSION_MISMATCH: Unsupported <type> protocol version <actualVersion>.
The <type> payload must use a supported protocol version.
Serve a <type> payload generated by this runtime.
https://markless.dev/errors/MARKLESS_PROTOCOL_VERSION_MISMATCH
```

Words in angle brackets change from case to case.

## How to fix it

Start with the suggestion in the message above.
