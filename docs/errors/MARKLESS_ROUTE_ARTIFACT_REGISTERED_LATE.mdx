**Error** from the compiler, while it builds your `.tsrx` files.

## What happened

Markless prints the message, the reason, and a suggestion:

```text
MARKLESS_ROUTE_ARTIFACT_REGISTERED_LATE: MARKLESS_ROUTE_ARTIFACT_REGISTERED_LATE: Client route artifact <source> was registered after its primary module transformed. Register every production route artifact before transformation begins.
The primary module has already been compiled without knowing it composes a route artifact, so its emitted graph would be wrong.
Register every production route artifact before transformation begins.
https://markless.dev/errors/MARKLESS_ROUTE_ARTIFACT_REGISTERED_LATE
```

Words in angle brackets change from case to case.

## How to fix it

Start with the suggestion in the message above.
