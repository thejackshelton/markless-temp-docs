**Error** from the compiler, while it builds your `.tsrx` files.

## What happened

Markless prints the message, the reason, and a suggestion:

```text
MARKLESS_BARE_ARM_INTERPOLATION: `{<expressionSource>}` stands alone as this arm's whole body. A standalone expression container is not a template output node, so the arm has no markup of its own and its text has nowhere to live but the element around it — which erases whatever the other arm rendered there.
Template output is an element, a fragment, or a control-flow construct. A statement container that needs to render text says so with a fragment, which gives the text its own marker range inside the arm.
Wrap it in a fragment: <wrapped>
https://markless.dev/errors/MARKLESS_BARE_ARM_INTERPOLATION
```

Words in angle brackets change from case to case.
