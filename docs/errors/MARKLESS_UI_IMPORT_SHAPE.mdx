**Error** from the compiler, while it builds your `.tsrx` files.

## What happened

Markless prints the message, the reason, and a suggestion:

```text
MARKLESS_UI_IMPORT_SHAPE: Line <line> imports from `<importSource>` with an unsupported shape; <fix>.
Application value imports from a family subpath or a namespace can expose source files to dependency optimization instead of using the package root export surface.
Replace this declaration: <fix>.
https://markless.dev/errors/MARKLESS_UI_IMPORT_SHAPE
```

Words in angle brackets change from case to case.

## How to fix it

Start with the suggestion in the message above.
