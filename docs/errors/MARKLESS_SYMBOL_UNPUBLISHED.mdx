**Error** from the build tools, while Vite builds or serves your app.

## What happened

The error message reads:

```text
MARKLESS_SYMBOL_UNPUBLISHED: <type> <normalizedId> was loaded before its owner <ownerSource> published a final compile.
```

Words in angle brackets change from case to case.

## How to fix it

If you see this error, open an issue on the [Markless repo](https://github.com/compiled-run/markless/issues) with the steps that cause it.

This page has no guide yet. [Help write it](/contributing/improve-these-docs).

`@markless/bundler` raises this code. Source:
