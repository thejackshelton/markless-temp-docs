**Error** from the compiler, while it builds your `.tsrx` files.

## What happened

Markless prints the message, the reason, and a suggestion:

```text
MARKLESS_ARTIFACT_CHILD_RENDER_INVALID: MARKLESS_ARTIFACT_CHILD_RENDER_INVALID: <<componentName>> renderSsr must return static HTML.
The materialized edge is the delegate rendered output, so an output without HTML leaves nothing to inline.
Return an object with a string `html` field from renderSsr.
https://markless.dev/errors/MARKLESS_ARTIFACT_CHILD_RENDER_INVALID
```

Words in angle brackets change from case to case.

## How to fix it

Start with the suggestion in the message above.
