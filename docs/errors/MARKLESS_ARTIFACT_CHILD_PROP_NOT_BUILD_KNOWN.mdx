**Error** from the compiler, while it builds your `.tsrx` files.

## What happened

Markless prints the message, the reason, and a suggestion:

```text
MARKLESS_ARTIFACT_CHILD_PROP_NOT_BUILD_KNOWN: MARKLESS_ARTIFACT_CHILD_PROP_NOT_BUILD_KNOWN: <<componentName>> prop <prop> must be a build-known static value. Runtime component execution is not a fallback.
A delegate is rendered once at build time, so every prop it reads must be a value the compiler can read at build time.
Pass a static value, or compose the child as TSRX source.
https://markless.dev/errors/MARKLESS_ARTIFACT_CHILD_PROP_NOT_BUILD_KNOWN
```

Words in angle brackets change from case to case.
