**Error** from the compiler, while it builds your `.tsrx` files.

## What happened

Markless prints the message, the reason, and a suggestion:

```text
MARKLESS_RENDER_DATA_STYLE_UNLINKED: MARKLESS_RENDER_DATA_STYLE_UNLINKED: Render data for <source> links scoped style module <styleModule>, which this link does not carry.
A scoped style that is compiled but never linked ships a component whose markup renders unstyled in the consuming app, with nothing at build time to show it went missing.
Register the scoped style virtual module alongside the render-data module it belongs to before the link is read.
https://markless.dev/errors/MARKLESS_RENDER_DATA_STYLE_UNLINKED
```

Words in angle brackets change from case to case.

Start with the suggestion in the message above.
