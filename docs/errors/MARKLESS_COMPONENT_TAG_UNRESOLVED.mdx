**Error** from the compiler, while it builds your `.tsrx` files.

## What happened

Markless prints the message, the reason, and a suggestion:

```text
MARKLESS_COMPONENT_TAG_UNRESOLVED: Cannot resolve `<<tagName> />` because `<rootName>` is not imported in this file.
The compiler links a child component to the module it comes from at build time. Without an import it cannot find the component to render, and dropping the tag silently would delete the subtree.
Import the object that holds the component, for example `import * as <rootName> from './<rootName>.tsrx';` or `import { <rootName> } from './<rootName>.ts';`.
https://markless.dev/errors/MARKLESS_COMPONENT_TAG_UNRESOLVED
```

Words in angle brackets change from case to case.
