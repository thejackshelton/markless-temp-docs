**Error** from the compiler, while it builds your `.tsrx` files.

## What happened

Markless prints the message, the reason, and a suggestion:

```text
MARKLESS_STATE_REPEAT_ROW_SCOPE_UNSUPPORTED: <apiName>() creates "<name>" inside a keyed @for row. Per-row cells need per-row graph scopes, which do not exist yet.
Keys give rows identity, but each row would need its own cell keyed by row identity across reorder and resume. The current graph payload can only plan stable component-owned cells.
Lift the state to a collection on the parent: use one state() holding per-row data keyed by the row key.
https://markless.dev/errors/MARKLESS_STATE_REPEAT_ROW_SCOPE_UNSUPPORTED
```

Words in angle brackets change from case to case.
