**Error** from the compiler, while it builds your `.tsrx` files.

## What happened

Markless prints the message, the reason, and a suggestion:

```text
MARKLESS_CAPTURE_METADATA_MISSING: MARKLESS_CAPTURE_METADATA_MISSING: Parent module <parent> composes imported child <specifier>, but its compiled artifact has no current capture metadata. Rebuild the child with the current Markless compiler and clear any stale build cache.
Composing a child whose capture metadata is stale or absent would link captures against an artifact this compiler did not produce.
Rebuild the child with the current Markless compiler and clear any stale build cache.
https://markless.dev/errors/MARKLESS_CAPTURE_METADATA_MISSING
```

Words in angle brackets change from case to case.

## How to fix it

Start with the suggestion in the message above.
