**Error** from the compiler, while it builds your `.tsrx` files.

## What happened

Markless prints the message, the reason, and a suggestion:

```text
MARKLESS_REPEAT_ROW_HANDLERS_UNWIRED: This @for row has an event handler the browser cannot wire
A row handler receives its item from a collection the browser can read again: one on the graph, or a property path on the item of an enclosing keyed row.
https://markless.dev/errors/MARKLESS_REPEAT_ROW_HANDLERS_UNWIRED
```
