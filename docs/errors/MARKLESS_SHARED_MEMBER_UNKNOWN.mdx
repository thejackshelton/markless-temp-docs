**Error** from the compiler, while it builds your `.tsrx` files.

## What happened

Markless prints the message, the reason, and a suggestion:

```text
MARKLESS_SHARED_MEMBER_UNKNOWN: Cannot read "<source>" because the <definitionName>() shared state declares no member named "<member>".
A member read is lowered into a path subscription on a declared graph node. A path the node never declares reads undefined on every render and after resume, so the code that depends on it silently does nothing.
Declare "<member>" in the state() initial value of <definitionName>(), or read a member the definition already declares.
https://markless.dev/errors/MARKLESS_SHARED_MEMBER_UNKNOWN
```

Words in angle brackets change from case to case.
