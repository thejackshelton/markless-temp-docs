**Error** from the compiler, while it builds your `.tsrx` files.

## What happened

Markless prints the message, the reason, and a suggestion:

```text
MARKLESS_ATTACH_HOST_ELEMENT_REQUIRED: Cannot bind attach={<source>} on component <owner>. attach installs DOM behavior and needs a concrete host element owner.
Element behaviors are resumed by locating the owning DOM element. A component is not a DOM locator and may render zero, one, or many host nodes.
Move attach={...} to a host element such as <canvas>, or make the component forward behavior to a known host element in its own TSRX body.
https://markless.dev/errors/MARKLESS_ATTACH_HOST_ELEMENT_REQUIRED
```

Words in angle brackets change from case to case.

Start with the suggestion in the message above.
