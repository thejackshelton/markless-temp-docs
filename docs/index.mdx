In many frameworks, the browser runs every component again before one button works. Markless skips that.

You write plain values like `count++` in `.tsrx` files. Markless updates only the text that changed. Click **Next step**.

<StartHeroFigure />

Notice step 3: one chunk runs, one text node changes, and no component runs again.
